Installer Model Y Check

Sur iPhone / iPad

Ouvrez ce lien dans Safari, touchez le bouton Partager, puis « Sur l’écran d’accueil » (ou « Ajouter à l’écran d’accueil »), puis Ajouter. Activez « Ouvrir comme app web » si l’option apparaît.

Sur Android

Ouvrez ce lien dans Chrome, puis le menu ⋮ et « Installer l’application » ou « Ajouter à l’écran d’accueil ». Vous pouvez aussi utiliser le bouton d’installation de cette application.

Sans réseau

Ouvrez l’application une première fois avec Internet. Attendez le message « Prêt hors ligne » avant de couper la connexion. Les contrôles et notes restent disponibles sur ce navigateur.

Une application installée peut avoir un stockage distinct selon le navigateur. Vérifiez votre bilan après installation et conservez un export.
